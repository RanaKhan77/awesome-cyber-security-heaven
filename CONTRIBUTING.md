# Contributing to Awesome Cyber Security Heaven ☁️

Thank you for helping build the most trustworthy free-security-tools list on GitHub!

## Entry criteria (all three required)

1. **Free or free-tier** — no paid-only tools. Freemium services must be tagged `(free tier)` or `(freemium)`.
2. **Actively maintained** — meaningful activity within the last 12 months (classics with stable,
   battle-tested status may be exempted — the maintainers make the call).
3. **Professional value** — a one-line "what it does + when to use it" case that a working
   security professional would endorse.

## House rules

- One line per tool (~15-25 words). No marketing fluff, no star counts, no push dates.
- Disclose the license inline whenever it is **not** MIT/Apache/BSD-class permissive:
  `(GPL-3.0)`, `(AGPL-3.0)`, `(free, proprietary)` etc.
- Tools intended for offensive use are framed for **authorized testing** contexts.
- Entries are ordered best-first within each section.
- Search the list first — duplicates are closed.

## How to submit

1. Open a PR adding your entry to the correct section (alphabetical is fine; maintainers re-order).
2. Use the exact format: `- [Name](url) — what it does, when to use it. (license tag)`
3. For your own projects: add `(maintainer's project)` — transparency builds trust, we won't
   reject honest self-submissions that meet the criteria.

By submitting, you agree your contribution follows these rules and is released under CC0.
