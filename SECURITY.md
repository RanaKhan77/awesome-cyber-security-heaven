# Security Policy

## Supported Versions

This repository is a curated list of links and tool references — there is no
runtime code to patch. The `links.yml` workflow only validates URLs.

| Version | Supported |
| ------- | --------- |
| main branch | ✅ |

## Reporting a Vulnerability

This repo is part of the **2MNY Security** open-source family. If you find a
security issue in:

* **A tool we list** → report to that tool's own maintainer (every entry links
  to its upstream repository).
* **Our automation / workflow files** → email **security@2mny.com** with
  details and a reproduction path. We answer within 72 hours.
* **The 2MNY platform itself (2mny.com)** → email **security@2mny.com** —
  please do not test against the production platform without written
  permission. Responsible disclosure is welcome; unauthorized scanning is not.

We credit every accepted report in the repo's acknowledgment section unless you
prefer to stay anonymous.
