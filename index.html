FAQ

❓ Frequently asked questions

What the list is, how tools get in, and how to use it well.

What is Awesome Cyber Security Heaven?
A hand-curated map of the 498 best free cybersecurity tools — pentesting, bug bounty, OSINT, threat intelligence, DFIR, DevSecOps and AI/LLM security. Every entry is license-verified and sorted into 14 themed realms, from The Armory to The AI Forge.
Are all 498 tools really free?
Yes — the editorial bar admits free and free-tier tools only: no paywalls, no SaaS wrappers. Each entry is license-checked (MIT, Apache-2.0, GPL and friends) so you know what you can use commercially before you click.
What are the realm PDF dossiers?
Every realm ships as a designed, printable PDF dossier — a deep-research report census-synced with live GitHub stats, license mix and the full curated inventory. Free forever under CC0, regenerated whenever the list changes.
How do I get a tool listed?
Open an issue or pull request on the list repository. The bar: an OSI-compatible license, real maintenance (or historical significance) and a niche the list actually needs. Every submission is researched before it lands.
